# T32 验收报告：手机上下文面板的组成环形图

## 结论

会话上下文面板现在有一张三扇区环形图：系统 / 工具 / 消息，图例给出数值（tok）与百分比，
总面积的中心显示合计 token。原来的三行重复数字已并入图例。手机截图实测可读。

## 真机结果

- 设备：`e85bf1e`（Xiaomi，Android 17），dsh-go 1.1.0，web profile。
- 安装回执（脚本写入手机后拉回）：`status: ok`、
  `rendererMatches: true`、
   安装后的 `lib/dsh/go-view.js` SHA-256 `f6d77c4686106460f1ffb1721e1e12afa744225f6dba32996781aaec67c1ce26`。
- 真机目视：环形图可读，图例三行 `系统 / 工具 / 消息` 完整显示，各自带 tok 数值与百分比，
  圆心显示合计。修复前的旧画面把「工具定义」压成「工…」，两版对照same会话即可分辨。
  设备截图不随仓库提交。

## 两个真机发现（都已修）

1. **图例标签列只够两个汉字**。第一版直接复用行标签，`工具定义` 被压成 `工…`。
   宿主布局是「色块 + 8 + 标签 + 8 + 数值 + 百分比固定 52」，没有可调空间，
   因此环形图改用短标签：中文 `系统 / 工具 / 消息`，英文 `Sys / Tools / Msgs`；
   下方 keyValue 行仍保留全名。
2. **同版本重装会被包管理器跳过**。两次候选都是 0.18.7，第二次 `dsh plugin add` 返回 0
   但磁盘上还是旧渲染器，重启也没用。改为 0.18.8，并让安装脚本在装完后读回
   `lib/dsh/go-view.js` 重算哈希：对不上就回执 `stale`，不再以退出码为准。

## 实现

- `src/dsh/go-view.ts`：`goContextData` 增加 `share`（`finite()` 后的三个 token 数，缺数据为
  `null`）；会话视图在「上下文构成」下加一个 `chart`（`kind: donut`、`unit: tok`），
  类目用新增的短标签副本；删掉三行重复数字。
- `tests/go-view.spec.ts`：固定唯一 chart 节点、kind/unit/类目顺序、绑定路径、
  `share` 的完整与缺失取值、标签各出现一次、全局视图无 donut。

## 未覆盖

- 全局（非会话）面板不显示这张图，这是设计选择。
