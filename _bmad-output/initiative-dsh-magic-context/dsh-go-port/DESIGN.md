# Android dsh-go 原生适配短设计

状态：2026-11-17 用户批准，T23 采用本设计实施；手机运行验收尚未开始。

## 目标

同一个 `@elvisw/dsh-magic-context` 包同时服务 DSH Web 和 Android dsh-go。保留已有服务端语义，在手机使用宿主提供的原生组件，不移植浏览器 DOM，不修改 Flutter App。

目标为用户实装的 dsh-go `1.1.0`、手机本机引擎；iOS、SSH、中转不纳入本轮运行验收。

## 手机上的操作路径

1. 对话输入框上方显示一个 Magic Context 状态条，例如“上下文 62% · 待回收 3”，文字不超过宿主的 24 字限制。生成时遵循宿主隐藏状态条的规则。
2. 点击打开原生“上下文”面板：先看本会话压力及系统/工具定义/消息构成，再看历史摘要、记忆、待回收队列、维护、警告与最近操作。缺失值显示 `—`，不把未知写成 0，不添加不存在的指标。
3. 原生“向量检索”面板显示当前已生效的 provider、模型、探测维度、覆盖率和重建状态；提供加载模型、测试连接、开始重建、暂停、继续。加载得到的模型 ID 可复制到宿主原生配置中的模型字段，不写静态供应商模型表，不另造配置编辑器。
4. 配置入口沿用 App 自带的插件设置页。只补必要的说明/分组元数据，不改变默认值、校验和 volatile 语义。切回本地也在该配置页进行，不另加绕过宿主配置保存机制的“直接回滚”写配置动作。
5. 已有六个斜杠命令与工具使用 App 的通用原生呈现，不新增工具卡、快捷按钮或命令。

## 布局与语言

- 状态条只放即时摘要；详情使用宿主的 stack、metric、keyValue、list、actions、confirm 等组件，不重做桌面浮层或引入新主题。
- 两个 panel 使用唯一 ID；上下文 panel 从会话入口打开时严格按 `sessionId` 取数。从“全部功能”打开时明确标注全局视图，不冒充当前对话，也不任选一个会话填数据。
- 中文是完整交付项；英文同样保留。标题、状态、空态、错误、确认和按钮按宿主 locale 生成；模型 ID、协议名、环境变量名保持原样。
- 上下文数字直接来自现有 summary。手机负责展示，不重新统计 token，不导入整份浏览器脚本。

## 操作约束

- 向量操作只读当前已生效配置，不复制 Web 的 dirty/Save 草稿流程。保存配置和查看面板不自动探测或重建。
- 开始重建前显示目标模型和缺失条目数并确认；无记忆、缺模型/密钥、未探测等情况给出明确原因。迁移/暂停期间不并发加载模型或测试连接；暂停与继续复用原状态机。
- 网络动作使用宿主 deferred 协议并处理取消；重建快速提交后台任务，不把整次重建挂在 3 秒 invoke 窗口内。操作期间配置目标变化时，不显示旧目标的成功结果或对新目标自动执行动作。
- 关键拒绝条件在服务端执行，不依赖按钮是否禁用：记忆启用、必要密钥、探测与非空覆盖率；加载/探测还须确认后台任务不是 running/paused。网页保留现有呈现逻辑，不为复用浏览器 IIFE 引入新打包链。
- 在插件父级监听宿主 `loader/volatile-update`。每次有效配置提交到 local/off 时立即调用现有 state-only disarm，监听不依赖面板是否打开；再切回相同远程配置仍须显式开始。不用状态轮询代替配置变更事件。
- 探测请求捕获完整目标和密钥指纹，await 后与当前目标比较；取消或发生变化则返回取消/`target-changed`，不写探测缓存、不显示成功。缓存淘汰键从所写 entry 派生，不从变化后的配置派生。
- 不提供密钥输入框，不发送密钥到面板数据。沿用环境变量名配置；手机用户自行在 `$DSH_HOME/.env` 中设置密钥并重启引擎。该文件是本机明文文件，不上传、不由代理读取或改写；不建议将密钥写进终端命令历史。App 凭据库不会自动变成插件的 `process.env`，本轮不增加凭据服务适配。

## 生命周期与验收边界

通过可选的 `ctx.inject(['dshGo'], ...)` 注册；无桥接的电脑端照常加载。数据仅在订阅期间更新，取消或卸载后释放订阅和定时器。遥测服务不能随 Web 路由的重挂载被提前关闭。

候选包完成前不再操作手机。完成后只做一次预定的 Android 用户路径验收；允许复用用户明确授权的现有 profile，但配置可恢复、插件数据和会话单独划定，不清理原数据。模拟嵌入服务与真实模型调用的结论分别标注，不宣称完整移动端 parity。
