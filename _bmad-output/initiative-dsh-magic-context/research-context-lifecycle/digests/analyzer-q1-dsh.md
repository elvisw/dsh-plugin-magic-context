1. **Load-bearing:** request messages derive from the admitted Session surface. `buildRequest` logs config/tool headers and route context, then reads `session.deriveMessages()` and `toolHistory()`. Boundary and attempt events do not produce messages. `packages/core/agent-loop/src/agent.ts:656-743` (buildRequest) @ fcc0ad46; `packages/core/session/src/index.ts:999-1029` (deriveMessages) @ fcc0ad46.
2. Prompt assembly and pre-step admission operate before request history is committed. Tools remain provider-authoritative; required complete sections are restored. Rejected admission closes the turn without a step; an initially empty accepted batch spends no model call. `packages/core/system-prompt/src/index.ts:620-695` (assemble) @ fcc0ad46; `packages/core/agent-loop/src/agent.ts:283-312` (preStep) @ fcc0ad46.
3. **Load-bearing:** deprecated `agent/request` changes controls, not content or the already-captured model selection. `buildRequest` freezes messages, array and envelope. `llm/stream` may wrap or short-circuit but its contract prohibits rewriting loop-built content. Adapter serialization/projection can still differ from Session messages. `packages/core/agent-loop/src/agent.ts:612-652` (prepareRequest) @ fcc0ad46; `packages/core/agent-loop/src/agent.ts:726-742` (buildRequest) @ fcc0ad46; `packages/llm/llm/src/index.ts:63-75` (stream) @ fcc0ad46.
4. **Load-bearing:** durable edits append new decisions, preserving original events. Replacement endpoints must be current nodes in positional order, with complete source references. Tool-result replacement targets exactly one current result and changes content only; the system head has stricter replacement rules. Registered logged message projections are another surface mechanism; missing/changed required interpreters make reads fail. `packages/core/session/src/surface.ts:301-365` (surfaceOpOf) @ fcc0ad46; `packages/core/session/src/surface.ts:455-546` (assertToolResultRewrite) @ fcc0ad46; `packages/core/session/src/surface.ts:698-709` (_assertProjections) @ fcc0ad46.
5. **Load-bearing:** memory append and durable flush are separate. Appends validate and freeze lossless JSON before insertion; post-commit observer errors cannot veto an append. Flush awaits durability listeners and propagates failures. Optional checkpoint policy flushes before downstream requests/tool execution. `packages/core/session/src/index.ts:806-837` (append) @ fcc0ad46; `packages/core/session/src/index.ts:1341-1357` (flush) @ fcc0ad46; `packages/session/session-checkpoint-policy/src/index.ts:63-82` (apply) @ fcc0ad46.
6. Cancellation does not roll back committed events. Admission/preparation cancellation prevents the accepted batch from being committed; streaming cancellation may settle interrupted content or an attempt. `packages/core/agent-loop/src/agent.ts:490-539` (step) @ fcc0ad46; `packages/core/agent-loop/src/agent.ts:630-652` (prepareRequest) @ fcc0ad46.
7. Tool pipelines execute pre/around/post hooks and read-only result observers. Caller cancellation cannot be suppressed by replacing wrapper signals. Batch settlement drains started bodies, records results in model order and supplies errors for skipped calls. `packages/core/tools/src/pipeline.ts:253-325` (dispatchToolBody) @ fcc0ad46; `packages/core/tools/src/batch.ts:243-279` (BatchSettlement) @ fcc0ad46.
8. Pair balance is explicitly checked by compaction selection/recovery; it was not established as a universal append invariant. Resume acquires a writer, reads persisted events and applies crash closers before publication. `packages/compaction/compaction-basic/src/region.ts:337-357` (validateSurfaceRegion) @ fcc0ad46; `packages/core/agent-loop/src/index.ts:784-809` (resumeWith) @ fcc0ad46.
